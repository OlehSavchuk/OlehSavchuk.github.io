Net-proton cumulants: baryon and quark stopping

Model of O. Savchuk, Phys. Rev. C 111, 024913 (arXiv:2407.17670). Stopped charge plus pair creation, with recombination between two subsystems under detailed balance.

Parameters

The energy dependence of α, B̄ and the switch β(E) are simple placeholders, not the values the paper extracts from STAR data.

baryon stopping quarks, no recombination quarks, recombined baryon to quark switch

Stopped charge only, at the energy marker. Ratio of recombined hadron values to the quark values before recombination. Left end is full equilibration (α₁₁ = α), right end is no diffusion (α₁₁ = 1).

Equations used 
ω = κ₂/κ₁,  Sσ = κ₃/κ₂,  κσ² = κ₄/κ₂        (1-3)
κₙ = κₙ(stop) + κₙ(pair)

Baryon stopping, binomial acceptance α        (8-11)
 κ₁ = αB_s
 κ₂ = B_s α(1-α)
 κ₃ = B_s α(1-α)(1-2α)
 κ₄ = B_s α(1-α)(1-6α(1-α))

Quark stopping, 3B_s quarks, each in the
window with probability α                     (12)
 before recombination κₙ → 3^-(n-1) κₙ

Recombination, hadrons move 1 → i with
probability α_ji                              (13-14)
 F(k) = F⁰( φ(k|α_1i), φ(k|α_2i) )
 φ(k|α) = ln(1-α+α eᵏ)
 Eqs. 16-19 follow from expanding F in k.

Two subsystems: 1 = window, 2 = outside
 α₁₂ = 1-α₁₁,  α₂₂ = 1-α₂₁
 detailed balance: α₂₁ = (κ₁/κ₂) α₁₂
 κ₁/κ₂ = α/(1-α), so α₁₁(eq) = α
Input cumulants: ideal gas with exact
conservation, i.e. B_s (or 3B_s quarks) split
binomially between 1 and 2.

Pairs, B̄ pairs, acceptance α_p                (21-24)
 κ₁ = κ₃ = 0
 κ₂ = 2B̄ α_p(1-α_p)
 κ₄ = 2B̄ α_p(1-α_p)(1+6α_p(1-α_p)(ω[B̄]-1))

Switch: stopped cumulants = β κ(quark, recombined)
 + (1-β) κ(baryon),  β(E) = 1/(1+exp(-(E-E_tr)/w))
